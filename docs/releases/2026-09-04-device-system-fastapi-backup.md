## 备份目的

保存设备管理、系统设置和 FastAPI 后端重构阶段的可运行代码，作为后续继续开发和合并主分支前的回退点。

## 已包含

- FastAPI/Uvicorn 应用入口和 OpenAPI 文档。
- 运行时控制路由：摄像头、算法、录制、手部关键点可视化。
- 设备管理路由：身份、网络、健康、报警器、备份恢复、日志清理。
- 系统设置路由：时间/NTP、存储策略、服务端口、恢复出厂确认。
- 工作台、设备管理、系统设置前端页面。
- 设计说明、流媒体脚本和相关 C++ 处理链路变更。

## 未包含

- 运行日志、录像文件、私钥和证书。
- Python `__pycache__`。
- `output/` 下的动态库和运行二进制。
- 设备本地身份、网络、时间和服务配置缓存。

## 注意事项

网络配置接口目前负责参数校验和配置持久化，不会直接修改物理网卡，避免误配置导致设备失联。恢复出厂接口目前是确认和审计入口，正式清除策略需要管理员权限和产品化存储方案。
