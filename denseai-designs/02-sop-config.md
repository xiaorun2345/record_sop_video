# 02 SOP 配置与步骤管理

## 页面目标

让工程师通过表单和可视化流程配置 SOP，不再直接编辑 `sop_config.txt`。页面必须支持步骤的增删改查、排序、复制、草稿、测试、发布和版本回滚。

## 页面布局

- 左侧：SOP 列表、搜索、状态筛选和新建按钮。
- 中部：步骤列表与流程时间线；显示步骤编号、名称、目标、状态和拖拽排序。
- 右侧：当前步骤属性编辑，包括目标、ROI、确认帧、超时和异常联动。
- 底部：保存草稿、试运行、发布版本、导入、导出和版本历史。

## 步骤增删改查

- 新增：创建步骤并填写名称、说明、目标和成功条件。
- 查询：查看步骤详情、绑定 ROI、历史版本和关联作业。
- 编辑：修改步骤属性，自动标记为草稿变更。
- 删除：仅允许删除未被已发布版本引用的步骤；已发布版本通过复制生成新版本后修改。
- 复制：复制当前步骤，自动生成新的步骤 ID。
- 排序：拖拽调整顺序，保存时校验步骤 ID 唯一。
- 启用/停用：停用步骤不参与新作业，但不影响历史记录。

## 单步骤字段

- `id`、`name`、`description`、`reference_media`。
- `required_objects[]`：目标标签和最小数量。
- `hand_roi`：绑定的手部作业区域。
- `min_confirm_frames`：连续确认帧数。
- `min_stage_sec`：步骤最短驻留时间。
- `timeout_sec`：超时时间。
- `max_hand_object_distance_m`：手物最大距离，0 表示关闭。
- `success_message`、`failure_message`、`warning_message`。
- `allow_skip`、`allow_retry`。

## 异常联动区

该区只提供业务配置，不暴露串口协议：

- 声光报警启用开关。
- 触发条件：步骤超时、目标缺失、手部距离异常、深度异常、推理异常。
- 动作固定为红灯闪烁 + 蜂鸣器。
- 持续时间：3 秒、5 秒、10 秒或持续到人工关闭。
- 测试红灯+蜂鸣器、立即关闭。
- 显示当前报警器连接状态和最近一次测试结果。

## 流程校验

发布前必须检查：步骤 ID 唯一、目标标签存在、ROI 存在、超时大于 0、确认帧为正数、模型已绑定、报警配置合法。校验失败不能发布。

## 建议接口

- `GET/POST /api/sops`：SOP 列表和新建。
- `GET /api/sops/{id}/versions`：版本列表。
- `POST /api/sops/{id}/draft`：创建或更新草稿。
- `POST /api/sops/{id}/validate`：发布前校验。
- `POST /api/sops/{id}/publish`：发布版本。
- `POST /api/sops/{id}/rollback`：回滚版本。
- `POST /api/alarm/test`、`POST /api/alarm/off`：测试和关闭报警。
